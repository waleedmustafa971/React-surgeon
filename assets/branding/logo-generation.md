## Final prompt

Use case: logo-brand.
Create a single finished, artistic yet clean professional logo for "React Surgeon", a local AI engineering agent that lets developers click a broken React UI element, trace its component source, make a precise code repair, and verify it in a browser.
Design an original memorable geometric emblem: a refined React-inspired orbital/component structure, with a deliberate precise cut in one flowing orbit resolved by a subtle integrated checkmark. The central small node represents the pinpointed source. The whole symbol should feel like precise repair and verified continuity, not a medical clinic. Merge these ideas into ONE coherent minimal silhouette rather than a collection of icons. Beautiful intentional negative space, consistent substantial stroke weight, balanced elegant geometry, identifiable at small sizes.
Place the emblem above a beautifully typeset wordmark reading exactly "React Surgeon". Contemporary premium sans-serif typography, careful kerning, confident restrained craftsmanship. Use deep midnight navy and teal/mint accents, consistent with the application's identity.
Flat vector-like graphic finish, crisp edges, plain white background, centered composition with generous whitespace. One primary logo lockup only, no presentation board, no mockup, no explanatory annotations, no tagline, no 3D, no glow, no shadows, no gradients, no robot head, no brain, no red cross, no literal surgical blade. Aim for a distinctive premium developer-tool brand, sophisticated and timeless.
