# @react-surgeon/shared

Shared TypeScript types and schemas for [React Surgeon](https://github.com/waleedmustafa971/React-surgeon) — selected elements, scenarios, proofs, verification results and the model provider interface.

This is an internal package. You probably want [`@react-surgeon/cli`](https://www.npmjs.com/package/@react-surgeon/cli) or [`@react-surgeon/vite-plugin`](https://www.npmjs.com/package/@react-surgeon/vite-plugin).
